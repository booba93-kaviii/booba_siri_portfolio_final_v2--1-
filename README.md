A responsive personal portfolio for Booba Siri, built with plain HTML, CSS and JavaScript. The original portrait asset is kept in `assets/booba-siri.jpg`.

## Open in VS Code
1. Extract the ZIP file.
2. In VS Code, choose **File → Open Folder** and select `booba_siri_portfolio`.
3. Open `index.html`.
4. If Live Server is installed, right-click `index.html` and choose **Open with Live Server**. Otherwise, open `index.html` directly in your browser.

## Personalise before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your real contact email.
- Replace `assets/booba-siri.jpg` with another portrait if you want (keep the same filename, or update both image paths in `index.html`).
- Edit the spoken introduction in the `introText` array in `script.js`.
- The project cards currently contain cautious summaries. Add your verified role, technologies, repository links and demo links when ready.
- Add a resume PDF and a download link when your resume is ready; the current label is intentionally marked **COMING SOON**.

## Voice and video note
The introduction is a portrait-based animated presentation with browser text-to-speech, not a recorded or lip-synced MP4. It tries to select a feminine-sounding English voice when one is available on the device. Available voices vary by browser and operating system; the voice selector lets visitors choose from installed English voices.

## Features
- Responsive dark editorial design with lavender, teal, blush and warm accents
- Animated name, portrait reveal, ambient particles and subtle cursor glow
- Browser speech introduction with voice selection, pause/resume and stop
- Expandable skill and project cards
- Learning journey timeline, contact section and back-to-top control
- Reduced-motion support and basic keyboard accessibility
