# BOOBASIRI — Personal Portfolio

Responsive portfolio for Booba Siri, B.Tech Artificial Intelligence & Data Science student at Velalar College of Engineering and Technology.

## Included
- About, introduction voice player, learning/skills map, projects, academic CGPA highlight, certificate gallery, journey and contact sections.
- CGPA shown as 9.7 / 10 (as provided).
- Four original project artwork thumbnails (illustrative visuals, not screenshots of deployed products).
- Eight certificate scans supplied by the owner, displayed in a responsive gallery with a full-screen preview.
- Mobile navigation and accessible keyboard-close lightbox.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Add a new certificate
1. Copy the certificate image into `assets/`, e.g. `certificate-9.jpg`.
2. Add a new `.certificate-card` inside the `.certificate-grid` in `index.html`.
3. Set the preview button's `data-certificate` to a unique number and use the image path in its `<img>`.

## Before publishing
Replace `YOUR_EMAIL@example.com` in `index.html` with the email address you want visitors to use. Add your resume when ready.

Project illustrations are concept artwork. Replace them with real screenshots when the corresponding project interfaces are ready to showcase.
